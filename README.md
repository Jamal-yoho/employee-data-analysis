# Employee Data Analysis
## About the Project
This project is about analysing employee data using Python. I cleaned the data and created charts to understand employee details like department, age and monthly income.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Files
- data/ – Contains the dataset files.
- notebooks/ – Contains notebooks for data cleaning, analysis and visualisation.
- requirements.txt – Contains the required Python packages.

## How to Run the Project
1. Download or clone the project from GitHub.
2. Open the project folder in VS Code.
3. Install the required packages using:
    pip install -r requirements.txt

4. Open the notebooks folder.
5. Run the required Jupyter notebooks.

## Report
The visualisation report is available in notebooks/employee_visualisation.html. Open it in a browser to view the charts.

## Conclusion
Through this project, I learned how to clean employee data, analyse it and create charts using Python.
